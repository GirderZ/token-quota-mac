# 验证范围

1.5.2 已在 Apple Silicon、macOS 27 上完成本地构建与实际界面检查。

自检包括 10 项额度解析、4 项时间显示、8 项颜色边界、23 项套餐处理以及原始图形轮廓归一化检查。图标还检查了深浅模式下的透明镂空，以及 18px、30px 的视觉效果。

1.5.2 的多桌面修复在临时验证构建中观察了系统桌面切换通知、卡片收起与重新显示状态；重新展开时确认窗口位于当前活动桌面，并检查了悬浮胶囊点击展开与 Escape 收起。正式构建已替换原目录应用并完成实际启动、同步检查。全屏应用、台前调度与多显示器的组合场景仍未全面验证。

仓库 CI 在 macOS arm64 环境构建、自检并生成安装包。CI 通过不等于所有桌面场景已验证。

尚未全面验证：其他真实套餐账号、macOS 13–26、多显示器、完整重启后的登录启动。源码目标为 macOS 13，但预编译包仅提供 arm64。
